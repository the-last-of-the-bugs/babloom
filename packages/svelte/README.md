# 🌸 BaBloom Svelte

![BaBloom Svelte](image.png)

> Svelte integration for BaBloom, a TypeScript-first rich-text editor.

`@tlob/babloom-svelte` provides Svelte components and utilities for building rich-text editing experiences with BaBloom.

It is powered by `@tlob/babloom-core`, the framework-independent editor engine behind BaBloom.

## ✨ Features

* 📝 Rich-text editing
* **Bold**
* *Italic*
* ~~Strikethrough~~
* Underline
* Headings
* Paragraphs
* Ordered lists
* Unordered lists
* Blockquotes
* Code blocks
* Inline code
* Links
* Text alignment
* Undo / redo
* Keyboard shortcuts
* Selection handling
* 🖼️ Image support
* Image insertion
* Image selection
* Editor events
* Content serialization
* Extensible editor architecture
* TypeScript-first API
* 🟠 Svelte integration

## 📦 Installation

### npm

```bash
npm install @tlob/babloom-svelte
```
